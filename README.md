# Clef - Backend

REST API for Clef, an educational platform for teachers and students focused on syllabus and teaching flow management.

**Stack:** Java 21, Spring Boot 3, PostgreSQL, Flyway, Spring Security, JWT

## Getting Started

1. Clone the repo
2. Copy `.env.example` to `.env` and fill in your values
3. Create a PostgreSQL database named `clef`
4. Run the application — Flyway will handle migrations automatically

## Requirements

- Java 21
- PostgreSQL 17
- Maven
